# v4.2.2 工作台优化记录

## 完成内容

1. 顶栏、文件树、工具栏、属性面板、状态提示及确认／批注／交接／结果／颜色／效果六类弹窗统一样式，支持浅色与深色。
2. 右侧栏默认展开，可独立折叠；双侧支持边缘悬停临时展开和点击固定展开，画布随折叠释放空间。
3. 用户提供的左右侧栏、文件夹展开／折叠 SVG 路径内置到图标精灵，使用 currentColor 适配主题。
4. 主题切换位于关闭进程按钮左侧，默认浅色。仅改变工作台及批注浮层，不改变产品主题或原文件。
5. 调色预览不写撤回历史，应用实际变化才记一次。取消、Escape、收起属性栏立即回滚，保留此前历史；边框自动补线同批回滚，投影选色取消恢复效果草稿。
6. 窗口缩小时浮层收回视口；输入框焦点统一为外层轮廓，避免双重描边。

## 侧栏悬停闪退修复
