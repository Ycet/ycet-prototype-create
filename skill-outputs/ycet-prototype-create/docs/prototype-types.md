# 原型类型

| 类型 | 展示 | 交互 |
| --- | --- | --- |
| pages | 多页面带设备框架平铺，默认列数取 Manifest | 页内状态可用，业务跨页只声明目标、不绑定导航 |
| demo | 左侧导航，右侧单个设备框架，窄屏折叠布局 | 同文件页面切换、双向高亮、返回、错误处理 |
| nonframe | 手机／PC 产品直接占据浏览器视口，无设备壳，覆盖式导航 | 同文件页面切换、返回、横竖屏适配 |
| direction | 组件说明与一个带框架首页 | 仅首页内交互，不展示其他正式页面 |

静态阵列保持框架尺寸，窄屏减列或阵列滚动。Demo 设备展示区用 ResizeObserver 按可用宽高缩小框架，导航不随缩放。无框架手机／PC 页面使用实际可视区域与 env(safe-area-inset-*)，不绘制仿真状态栏或外壳。

仅首次交付、显式验收或 Skill 开发时，在 Chrome、Edge、Firefox 的可用环境中验证 1440×900、1280×720、1024×768 和手机横竖屏。未运行的浏览器／真机标记未验证，桌面模拟不冒充真机。

## Demo 滚动与缩放（所有 prototype-demo 系列）

- 左侧页面导航限高并独立纵向滚动，长列表的每个页面都能访问；窄屏折叠后仍可上下滚动。
- 右侧默认根据可用宽高完整适配设备框架，窗口尺寸变化时重新适配。右上方固定提供缩小、当前比例、放大和“适应窗口”，只缩放原型，不缩放导航或工具栏。
- 手动缩放范围 10%–300%，每次调整 10 个百分点；放大超出展示区后支持纵向及必要的横向滚动，四个边缘均可到达。切页保持当前缩放。
- 页面自身长内容可上下滚动；有独立滚动容器时保留原交互。工具栏不随内容滚出视口。
- 使用标准 CSS transform 和实际尺寸占位，包含窗口 resize 回退；仅首次交付、显式验收或 Skill 开发时，在可用 Chrome、Edge、Firefox、Safari/WebKit 环境验证完整展示、长导航、缩放、滚动和窄屏。不可用环境如实标记未验证。


## 无框架显示与滚动

C 的根区域宽度占满实际浏览器视口，短页高度至少覆盖可用高度，长页自然滚动到末端；不压缩整张设计稿、不引入舞台灰边，不用 overflow-x:hidden 隐藏布局错误。设计内边距、居中阅读栏和空状态属于产品留白，保留。

document 使用自然文档滚动；app 用可收缩 flex/grid 与内部滚动容器。窗口变化、横竖屏及手机键盘变化时保持操作可达。安全区取真实四边 env 值，固定栏避免重复叠加。宽表格使用局部横向滚动，不撑宽根页面。

菜单可拖动、抽屉可滚动且不占产品布局；打开时管理焦点和背景滚动，关闭恢复；切页保留 DOM 和各页滚动，隐藏页不遮挡。C 不显示 B 的缩放工具栏，保留原生浏览器缩放。

图片完整等比适宽，长图滚动；不同宽高比可能留下图片自身空余区域，不能通过裁剪或拉伸强行铺满。需要改变此约束先确认素材／重构方案。浏览器演示不代表原生小程序或桌面系统 API 可用。

这些是制作要求；修改任务完成后按 prototype-validation.md 结束，不自动追加本节验收。
