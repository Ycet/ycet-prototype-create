# 功能二：通过浏览器开发者工具精准修改原型

## 目标

根据用户提供的 CSS 选择器、HTML 片段和修改要求，精准修改原型页面中的指定元素。

凡涉及原型 HTML 或图片承载页面写入/修改，必须按 `shared-editlog-rules.md` 记录。

## 触发条件

用户提供以下信息时直接执行本功能：

- CSS 选择器；
- HTML 代码片段；
- 针对某个页面元素的修改要求。

若缺少 CSS 选择器或 HTML 片段，先要求用户补充，不要猜测定位。

## 工作流程

1. 读取 `shared-editlog-rules.md`。
2. 根据 CSS 选择器和 HTML 片段，在 `prototype/pages/` 及相关原型文件中定位目标元素。
3. 若选择器匹配多个元素，先向用户确认要修改哪一个。
4. 只修改用户明确要求的元素，不顺手改动其他结构、样式或文案。
5. 修改后确认选择器仍有效；若选择器变化，说明等价的新选择器。
6. 追加 `prototype/docs/EditLog.md` 记录。
7. 向用户说明修改内容和文件。

## 定位原则

- 优先在 `prototype/pages/*.html` 中查找。
- 涉及 `index.html`、`prototype.html` 或 `prototype-vN.html` 时，必须确认用户确实要改容器或 demo 文件。
- 不因视觉猜测扩大修改范围。

## 完成标准

- 目标元素修改符合用户要求。
- 未引入无关改动。
- 选择器仍可定位目标元素或已说明新选择器。
- `EditLog.md` 已记录。
