# 原型类型

| 类型 | 展示 | 交互 |
| --- | --- | --- |
| pages | 多页面带设备框架平铺，默认列数取 Manifest | 页内状态可用，业务跨页只声明目标、不绑定导航 |
| demo | 左侧导航，右侧单个设备框架，窄屏折叠布局 | 同文件页面切换、双向高亮、返回、错误处理 |
| mobile | 全屏产品，无设备壳，菜单与覆盖式导航 | 同文件页面切换、返回、横竖屏适配 |
| direction | 组件说明与一个带框架首页 | 仅首页内交互，不展示其他正式页面 |

静态阵列保持框架尺寸，窄屏减列或阵列滚动。Demo 设备展示区用 ResizeObserver 按可用宽高缩小框架，导航不随缩放。移动端使用实际可视区域与 env(safe-area-inset-*)，不绘制仿真状态栏或外壳。

在 Chrome、Edge、Firefox 的可用环境中验证 1440×900、1280×720、1024×768 和手机横竖屏。未运行的浏览器／真机标记未验证，桌面模拟不冒充真机。
