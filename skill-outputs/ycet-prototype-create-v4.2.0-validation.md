## 变更

- 工作台完成结果必须覆盖原请求全部文件，拒绝缺项、重复、未知文件、无效状态及冒报冲突文件成功；错误结果可修正后重试，部分成功和附加图片资源登记保留。
- 元素 ID 先收集再分配，避让已有标识；页内重复标识在生成与守卫中拒绝。HTML 标签通过解析器定位，一次拼接，避免大资源被反复复制。
- CSS 选择器按顶层逗号切分，支持 `:is()`、`:not()` 和属性字符串；仍拒绝未限定页面作用域的顶层选择器。
- JS 轻量词法检查区分代码、字符串、注释、正则和模板插值；HTML 事件属性与页面 JS 使用相同的全局访问检查。保留本地 this/event 交互与网络调用检查。
- 邮件和电话链接在资源处理器与守卫中使用一致规则。
- 需求访谈取消目标轮数，保留一次一问、关键缺口补齐、一次完整审计和用户确认。
- UI Skill 默认推荐当前会话中最合适的 2–3 个；用户指定时直接沿用，查看全部和目录发现仍可用。视觉 Skill 服务于原有阶段及单文件契约。
- 已有标准原型普通修改沿用类型与 UI；首次制作／类型转换有明确回答则复用，否则提问。需求→UI→制作主流程、版本确认、截图承载及默认修改后直接结束保持。
- 工作台说明按启动、请求执行和维护拆分；原有 UI 功能规范保留，工作台前端资产未修改。
- 首次普通交付使用一个可用浏览器及产品相关视口，保留逐页、核心流程和独立离线验收；完整兼容矩阵用于 Skill 发布或明确的兼容验收。
- 扫描缓存只保存文件 stat 签名、类型和摘要；未变化文件复用，变化或重启后重新读取。发送、领取及写入前的摘要保护保留。
