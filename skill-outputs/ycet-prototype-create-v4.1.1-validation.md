# ycet-prototype-create v4.1.1 版本说明与验证记录

## 版本定位

- 发布包：[ycet-prototype-create-v4.1.1.skill](ycet-prototype-create-v4.1.1.skill)
- 包含 41 个可安装文件，是兼容 v4.1.0 的修订版本。
- 本版本明确功能四的首次目标交付边界：首次根据 HTML 或图片生成目标原型文件时保留首次交付验收；已经交付的目标原型后续修改、迭代和类型转换保存后直接结束。
- 该边界与版本元数据记录见：[v4.1.0 实施与验收记录](../docs/spec/v4.1.0/实施与验收记录.md)中的 v4.1.1 补丁发布章节。

## 核心变更

- 功能四首次基于来源 HTML 或图片生成目标文件，使用 `create`／`--purpose initial`，保留页面、核心流程、相关视口和独立离线运行验收。
- 已交付目标原型的后续局部修改、全局修改、增删页、迭代文件和类型转换使用修改路径；不因新文件名自动恢复验收，只有用户明确要求测试时才按范围执行。
- 同步入口路由、功能三／四说明、共享原型规范、验证边界、评估场景、入口标题、`VERSION`、生成器元数据和校验器期望版本为 4.1.1。
- 保持 v4.1.0 的无框架 PC／移动端原型、单文件资源内联、工作台文件保护和轻量化修改流程。

## 验证结果

| 检查 | 结果 |
| --- | --- |
| 版本一致性 | `VERSION`、Skill 标题、生成元数据、共享规范和评估文件均为 4.1.1 |
| 源码校验 | `validate_skill.py` 通过 |
| 发布包 | 41 个文件，过程文件过滤通过 |
| 源码／压缩包／安装目录 | 文件内容一致，Claude 兼容链接有效 |
| 功能回归 | 沿用 v4.1.0 已完成的生成器、工作台和 Chrome 验证；本补丁未重复全量浏览器回归 |

## 未验证项与边界

- 新增的行为评估条目用于描述规则，不等同于已完成独立 Agent 评估。
- 本补丁没有改变生成器运行时结构；浏览器、真机和复杂外部 HTML 的限制沿用 v4.1.0。
- 说明文档位于发布包同级，未改变 `.skill` 包内文件数量和安装结构。
