# v4.1.0 实施与验收记录

日期：2026-09-19。仓库源码与发布包已更新为 v4.1.0；全局安装已按后续授权同步，未执行 Git 提交。历史 Spec 归档沿用此前变更。

## 实现结果

- 功能三 C 改为无框架交互 Demo，输出 prototype-nonframe.html 及独立 vN 文件族，手机与 PC 端口使用实际浏览器视口。
- 构建器新增 nonframe 分支与内联 nonframe.css，不读取设备 HTML 模板，不输出设备尺寸、外壳或 Demo 缩放逻辑。元数据 frame=null，页面支持 document/app 两种布局。
- document 自然滚动，app 固定产品头尾并使内部内容区可滚动；根区域填满视口。动态视口、安全区、菜单拖动、抽屉焦点循环、背景滚动锁、切页滚动位置和历史返回集中在内联运行时处理。
- Manifest 扩展端口别名、canonicalPort 与 deviceCategory；移动 H5 与 iOS 保留不同语义。旧 mobile 输入提示后规范化为 nonframe，旧 HTML 的 mobile 元数据仍可校验；旧文件不自动重命名。
- 修改完成即结束规则写入 SKILL.md、功能三／四／五及共享规范；新增 prototype-validation.md 作为任务结束边界。方向预览修改也遵循该规则。
- 构建器 iterate/overwrite 默认 purpose=modify；create 默认 initial，类型转换可明确 --purpose modify。修改路径不调用 audit；--validate 仅供显式要求验收的修改任务。源摘要、资源解析及内联、目标路径和原子写入保护保留。
- 中英文 README、VERSION、评估场景与验证文档同步升级。工作台原有通用类型登记、状态锁和预览实现经回归可复用，未为新名称增设扫描特例。

## 限制与交付

无框架根布局不能自动重排任意作者写死宽高的业务片段；Skill 已要求制作时按端口处理页面 CSS。图片宽高比不同于视口时保留原比例，不承诺图片本身同时无裁切且铺满宽高。

新增 8 个行为评估场景，总计 38 个；当前完成代码测试和文档规则检查，未声称执行独立 Agent 行为评估。修改模式不调用 audit 有自动测试证据，但无法保证任何 Agent 都完全遵循文字约束；没有实际耗时／token 对照实验，不承诺降幅。

发布包：[ycet-prototype-create-v4.1.0.skill](../../../skill-outputs/ycet-prototype-create-v4.1.0.skill)。包包含可安装源码与测试，排除截图、工作台状态、缓存和临时过程文件；历史 v4.0.0、v4.0.1 包保留。
