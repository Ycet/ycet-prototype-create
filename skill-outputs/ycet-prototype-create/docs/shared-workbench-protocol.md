# 原型可视化编辑器工作台协议

## 适用范围

本协议由功能二启动和使用；其他功能可遵守其草稿、锁和请求边界，但不得自动启动或打开工作台。工作台负责本地预览、元素选择、批注、预览级草稿、变更包和结果展示；Agent 仍是唯一可以在用户点击“发送给 AI”后修改源文件的一方。

工作台入口：

```text
scripts/prototype_workbench.py
```

工作台只依赖 Python 3 标准库与浏览器原生能力。服务绑定 `127.0.0.1`，项目状态位于项目根目录 `.ycet-editor/`，不得写入 `prototype/`，也不得自动修改 `.gitignore`。

## 生命周期命令

仅在功能二首次需要展示项目或服务可能未运行时：

```text
python <skill目录>/scripts/prototype_workbench.py ensure --project-root <项目根目录> --add <HTML绝对路径>
```

- 同项目健康实例存在时必须复用，只增量同步 `--add` 文件。
- 实例不存在时在随机本机端口启动并尝试打开浏览器。
- 命令 JSON 输出始终包含 URL；`opened: false` 时必须把 URL 发给用户手动打开。
- 用户可以手动关闭服务。只有后续功能二再次需要工作台时才调用 `ensure`，不得后台自动重启。
- 顶部“关闭工作台进程”按钮必须始终二次确认；有未发送草稿时列出受影响 HTML 文件数量并明确草稿会丢失。
- 确认关闭后，网页调用受实例令牌、Host 与 Origin 校验保护的 `POST /api/shutdown`。接口先返回 `202`，再优雅停止 HTTP 服务、文件监听和系统对话框代理，并删除属于当前 PID 的 `server.json`；禁止从网页强杀任意 PID。
- 关闭成功后清空当前浏览器会话草稿、停止轮询并保留标签页显示“工作台进程已关闭”；不自动关闭标签页。
- 已生成或正在执行的 Agent 请求与结果不因工作台服务关闭而删除。Agent CLI 可在服务停止后继续执行，重新 `ensure` 后恢复请求状态和结果展示。
- 可重复提供多个 `--add`；未提供时递归扫描项目根目录内的 HTML，并忽略 `.git`、`.ycet-editor`、`node_modules`、虚拟环境与缓存目录。

明确只做增量同步时可用：

```text
python <skill目录>/scripts/prototype_workbench.py sync --project-root <项目根目录> --add <HTML绝对路径>
```

`sync` 只复用已由功能二启动的实例；实例不存在时只更新本地工作区登记，绝不启动或打开工作台。检查状态使用：

```text
python <skill目录>/scripts/prototype_workbench.py status --project-root <项目根目录>
```

## 工作区边界

- `workspace.json` 保存文件登记、来源、缺失状态、当前文件和缩放偏好，并兼容读取旧版本留下的分组与排序数据；网页端不再提供修改分组或排序的入口。
- 未发送批注、属性、文本、图片、CSS 和 `同步 pages` 草稿只保存在浏览器内存，关闭工作台即丢失。
- 左栏展示已登记文件，分组名称左侧显示本地文件夹图标，组内文件相对文件夹标题向右缩进；每个文件提供在新标签页打开和“从工作台移除”图标按钮。跳转与删除按钮默认隐藏，仅在对应文件行鼠标悬浮或键盘聚焦时显示；删除图标为红色。移除操作必须二次确认，只删除工作区登记和会话草稿，绝不删除、移动或重命名磁盘 HTML；刷新按钮递归扫描项目根目录并补入所有未展示的 HTML，同时恢复此前仅从工作台移除、但仍存在于磁盘的项目文件，忽略工作台状态、版本控制、依赖、虚拟环境与缓存目录。
- “清理缺失的文件”仅在存在缺失登记时展示；它只移除缺失文件的工作区记录，绝不操作磁盘。
- 外部 HTML 不再通过网页系统文件对话框登记；只有用户明确要求 Agent 使用 CLI `--add` 时才可登记，并在原始绝对路径修改。
- 没有 `prototype/` 或没有 HTML 时正常启动空工作台，不得关闭服务或伪造文件。
- 图片选择默认由浏览器原生文件选择器完成：网页通过隐藏 `<input type="file">` 弹出系统文件面板（macOS 上即访达），选中图片以字节流上传到受令牌保护的 `POST /api/assets/upload`（`Content-Type: application/octet-stream`，文件名经 `X-YCET-Filename` 传递），服务端校验扩展名、内容魔数与大小（上限 32 MiB）后存入 `.ycet-editor/uploads/` 作为临时预览资源，只登记路径并用于预览；发送前不复制到 `prototype/`、不修改图片或 HTML。
- 旧版 `POST /api/dialog` 系统文件对话框（Tk）仅保留为自动化/兼容路径；除非显式设置 `YCET_WORKBENCH_DIALOG_PATH`，网页不再调用。仍调用时对话框必须由 Python 进程主线程执行，`ThreadingHTTPServer` 请求线程只能提交任务并等待结果，禁止直接创建 Tk 根窗口；macOS 系统 Python 的 Tk 8.5 已知无法弹出面板且会挂起进程，不得将其作为新依赖。
- 文件监听发现外部变化时，无草稿文件刷新摘要与预览；有草稿文件标记冲突并禁止发送，直到用户刷新源文件并重新编辑。

## 预览与定位

服务只在 HTTP 响应中注入 `preview-runtime.js`，源 HTML 字节不变。选择结果必须包含：

- `fileId`、原始路径和文件 SHA-256；
- iframe `framePath`；
- CSS 选择器、标签、ID、类名和文本特征；
- 祖先链与兄弟序号。

预览路由必须以项目 `prototype/` 为 URL 根保留原 HTML 的目录语义：根级 HTML、`pages/`、`previews/`、`runtime-pages/`、设备框架及其嵌套 iframe 中的相对 `src`、`srcset`、`href`、CSS `url()` 和模块路径，都必须按源文件所在目录解析。响应内注入的 `<base>` 只能映射到当前 HTML 在预览路由中的等价目录，不能把 `pages/*.html` 的 `../assets/images/*` 重定向到缺失文件 ID 的路径；不得为修复预览而改写磁盘 HTML。为兼容历史页面，预览 CSP 仅额外允许官方 `https://cdn.tailwindcss.com`；新生成或重构页面仍必须本地化 CSS/JS，不能将该例外作为交付依赖。

中央红框区域本身就是内置浏览器视口，预览外框在所有缩放比例下都必须占满该区域，不得随 HTML 缩放、嵌套固定宽高、居中留白或按页面内容宽度扩张。缩放采用浏览器页面缩放语义：100% 以下通过改变 iframe 的逻辑视口和内部渲染比例缩放 HTML，缩小时逻辑视口相应变宽、变高；100% 以上放大内部预览层，外框物理尺寸始终不变。普通鼠标滚轮滚动当前 HTML 页面，`Ctrl+鼠标滚轮`在 HTML 区域内以指针为中心缩放；只有缩放大于 100% 时才允许按住中键二维拖动，拖动通过有边界的内部预览层 X/Y 偏移实现，不能依赖页面自身是否存在横向滚动条，并禁止移动或缩放浏览器外框。画布左下角常驻“Ctrl + 鼠标滚轮：缩放 HTML”和“放大后鼠标中键：拖动 HTML”两项提示，并设置为不接收指针事件。进入工作台时“选择元素”默认不激活，预览运行时不得显示悬浮框、已选框、元素名称或批注入口；用户主动点击后才进入选择模式。关闭“选择元素”后必须隐藏全部选择覆盖层，再次开启后需重新点击元素才显示选区。批注入口必须位于选区框外的右上角或右下角并与右边缘对齐；批注内容浮层靠近 HTML 可视区边缘时必须自动左右翻转并上下避让，不能被 iframe 裁切。同一元素已有批注时隐藏新增入口，删除该元素批注或清空当前文件批注后重新显示。

预览 iframe 的逻辑宽高始终跟随中央浏览器区域；页面内容超出视口时由 HTML 页面自身横向或纵向滚动，不得扩大外层 iframe 造成内容或控件被画布裁切。X/Y 输入展示元素当前视口坐标，写回时必须计算“新坐标 − 选中时坐标”的差量并叠加到元素原有 `left/top`；即使元素位于非零起点的定位容器中，数值增加 1 也只能移动 1 CSS 像素。静态元素需先转为相对定位，不能写入无效偏移。

Agent 必须以文件摘要和完整元素指纹共同定位。选择器不唯一、摘要不匹配、iframe 路径失效或文本特征冲突时，只报告冲突，不猜测修改。

草稿操作类型固定为：

| 类型 | 用途 |
| --- | --- |
| `annotation` | 元素批注 |
| `style` | 设计面板样式差异 |
| `text` | 文本节点替换 |
| `image-replace` | 本地图片替换 |
| `css` | 任意 CSS 属性和值 |
| `sync-pages` | 静态页到运行时页的受控同步 |

CSS 与样式值在预览中可自由应用；Agent 落实时必须拒绝远程 URL、`@import`、`javascript:`、`expression()`、越界路径和违反当前功能守卫的值。

## 会话草稿规则

- 切换 HTML 保留当前会话内各文件草稿，文件图标左侧显示红点。
- “清空修改”只清当前文件的样式、文本、图片、CSS 与 `同步 pages` 草稿，保留该文件批注和其他文件草稿。
- 属性数值输入框的每次变更实时同步到画布（逐键输入、键盘上下键与上下按钮微调均即时生效）；同一次聚焦会话内的连续调整合并为一次变更记录与一个撤销步（失焦或回车结束会话），点击发送、清空或撤回前会自动结束输入框会话；文本字段仍在失焦时提交一次。
- “撤回”撤销上一步右侧边栏操作：样式修改（一次点击撤销一次用户操作的整批属性，宽高联动同时恢复宽度与高度、四角圆角整体恢复）、图片替换（恢复上一次替换或回到原始图片）与文本内容修改（失焦提交后同样可撤回，恢复上一次文本或回到原始文本）；不覆盖批注与 `同步 pages`；输入框尚未失焦的修改在点击撤回时先提交为一步，再被整体撤回；撤回后预览与右侧栏输入同步恢复（含嵌套 iframe 内元素的撤回）；可连续回退且不设步数上限，发送成功或“清空修改”后历史清空；历史仅存浏览器内存，随会话失效。
- “清空批注”只清当前文件的全部批注，保留该文件其他类型草稿和其他文件批注；当前文件没有批注时按钮禁用。
- 用户可单独编辑或删除批注。
- “发送给 AI”聚合所有文件草稿。请求包成功写入磁盘后清空全部会话草稿；写入失败时全部保留。
- 发送仅生成机器可读变更包和可复制执行指令，用户须把指令粘贴到当前 Codex、Claude Code、OpenCode 或其他 Agent 会话；V1 不直接控制或启动 Agent。
- 交接弹窗必须展示请求 ID、文件数、操作数、状态和执行指令，并在支持的工作台视口内完整显示且不产生横向滚动。关闭按钮使用可辨识边框，和“复制指令”按钮保留至少 12px 间距；点击“复制指令”后立即关闭弹窗，并通过 Toast 如实反馈剪贴板成功或失败。只有浏览器剪贴板写入实际成功时才能提示“已复制”；失败时仍可从请求详情重试。
- 右侧状态条持续展示当前或最近请求，工作台重启后从磁盘恢复。“处理成功”状态卡提供位于“查看详情”左侧的关闭图标；点击只在当前浏览器会话隐藏该请求状态，轮询不得重新显示，且不得删除请求包、状态文件或结果。终态的结果详情弹窗必须约束在当前视口内，逐文件路径与原因文本自动换行；长内容只允许弹窗内容区纵向滚动，不得产生横向滚动或裁切。

## 变更包

请求位于：

```text
.ycet-editor/requests/<request-id>.json
```

顶层使用 `schemaVersion: 1`，包含请求 ID、项目根、生成时间和文件列表。每个文件包含来源、原始路径、显示路径、原始 SHA-256、操作与可选依赖组。

动态状态独立保存为 `.ycet-editor/requests/<request-id>.state.json`，不得改写原始请求包。状态固定为：

| 状态 | 含义 |
| --- | --- |
| `pending` | 变更包已生成，等待用户交给 Agent |
| `processing` | Agent 已原子执行 `request begin` |
| `success` | 全部文件成功 |
| `partial` | 部分文件成功 |
| `failed` | 没有文件成功或执行失败 |
| `aborted` | 用户在领取前取消，或 Agent 主动中止 |

旧请求缺少状态文件时，按 `.result.json`、事务清单和请求包依次推导终态、`processing` 或 `pending`。

正式请求包必须满足“JSON 文件名去掉 `.json` 后与包内 `requestId` 一致”且包含 `files`。Agent 可使用独立临时文件准备结果，但 `*.result.pending.json`、`*.state.json`、`*.result.json` 等状态或临时结果不得被识别为新请求；正式请求进入终态后必须立即解除活动请求和发送锁。

同一项目同时只允许一个 `pending` 或 `processing` 请求：

- 存在活动请求时禁止再次发送；活动请求终止后恢复。
- 活动请求中列出的文件及 `sync-pages` 静态来源文件锁定编辑；其他 HTML 仍可准备新草稿，但必须等待当前请求终止后发送。
- `pending` 请求可从工作台取消；取消不会恢复发送时已经清空的草稿。
- `processing` 请求不得由网页强制取消，只能由执行 Agent `complete` 或 `abort`。
- `request begin` 必须用原子事务目录领取；重复领取、非 `pending` 状态或另一个活动请求存在时拒绝。

领取请求：

```text
python <skill目录>/scripts/prototype_workbench.py request show --project-root <项目根目录> --request-id <请求ID>
python <skill目录>/scripts/prototype_workbench.py request begin --project-root <项目根目录> --request-id <请求ID> [--include <项目内图片目标或EditLog路径>]
```

`begin` 原子将状态从 `pending` 更新为 `processing`，建立修改前快照并按依赖组校验摘要。独立文件冲突不得阻断其他文件；同一依赖组任一文件冲突时整组不写。图片替换会新增/覆盖的项目内资源和本次需要更新的 `prototype/docs/EditLog.md` 必须在写入前通过重复 `--include` 纳入事务；外部 HTML 不包含 EditLog。新增且尚不存在的资源也要提供目标路径，事务会记录其“修改前不存在”。

Agent 执行规则：

1. 只处理 `begin` 返回的 `readyFileIds`。
2. 对每个元素重新解析源 HTML 并验证指纹唯一。
3. 在暂存内容中应用操作并运行当前功能要求的守卫。
4. 项目内普通成功修改按 `shared-editlog-rules.md` 追加 `prototype/docs/EditLog.md`；外部文件不写永久执行历史。
5. 结果 JSON 的 `items` 逐文件包含 `fileId`、`path`、`status` 与可选 `reason`；状态为 `success`、`failed` 或 `conflict`。成功项通过 `affectedFileIds` 登记本次实际改变的附加事务文件 ID；不得漏报图片资源或 EditLog。
6. 多个互不依赖文件允许部分成功，最终回复必须列出成功文件、失败/冲突文件和原因。

完成或中止：

```text
python <skill目录>/scripts/prototype_workbench.py request complete --project-root <项目根目录> --request-id <请求ID> --result <结果JSON>
python <skill目录>/scripts/prototype_workbench.py request abort --project-root <项目根目录> --request-id <请求ID> --reason <原因>
```

`complete` 将状态更新为 `success`、`partial` 或 `failed`；`abort` 更新为 `aborted`。工作台轮询状态与 `.result.json` 并展示逐文件结果；请求事务快照在完成或中止后清理，不提供用户撤回入口。

## `同步 pages`

`runtime-pages/*.html` 可映射到 `pages/*.html` 只是必要条件。“同步 pages”仅在对应静态页最近一次相关 Agent 请求满足以下条件时展示：该文件结果为 `success`、`beforeSha256` 与 `afterSha256` 均存在且不同、当前静态页摘要仍等于该 `afterSha256`，并且这次静态修改尚未被该运行时页成功同步。最近一次请求未真实改写静态页时不展示，也不得沿用更早批次。

点击后只添加 `sync-pages` 草稿，操作必须记录 `sourceRequestId`、静态页修改后摘要、静态页与运行时页 ID/路径。工作台把源请求中可直接复用的 `style`、`css` 和 `text` 操作映射到当前运行时预览，因此按钮变为绿色“已同步”且中央画布立即展示草稿效果；“清空修改”恢复运行时原始预览。必须再次发送后才允许 Agent 修改，成功完成该同步请求后入口隐藏，直到静态页产生新的真实成功修改。

执行时不得用静态文件直接覆盖运行时文件。必须在暂存副本中受控合并结构、内容和样式，并保留或重新生成功能三的：

- `channel: "ycet-prototype"` 与 `version: 1`；
- `navigate`、`set-screen`、`screen-changed`；
- 页面注册表、目标白名单、`event.source` 校验和框架中继。

静态源页与引用其修改的同步操作属于同一依赖组。写入前后必须验证 `prototype.html` 或当前版本 Demo 仍加载目标运行时页，功能三守卫与浏览器交互失败时整组不写。

## 功能五锁

打包前：

```text
python <skill目录>/scripts/prototype_workbench.py lock acquire --project-root <项目根目录>
```

- 健康工作台存在相关未发送草稿时命令失败，Agent 必须要求用户先发送或清空；不得自动处理草稿。
- 获取成功后保存返回的锁令牌。锁期间禁止发送工作台变更，但允许只读预览。
- 在 `finally` 路径释放，避免成功、失败或取消后遗留锁：

```text
python <skill目录>/scripts/prototype_workbench.py lock release --project-root <项目根目录> --token <锁令牌>
```

## 安全红线

- 不直接写源 HTML，不把预览 DOM 当作源文件或打包输入。
- 不接受目录遍历、远程资源、危险协议、未登记路径或非本机 Host/Origin。
- 不以工作台规避功能一静态页、功能三只读输入、功能四确认门禁或功能五全项目 SHA-256 保护。
- 不把外部文件修改写入项目 EditLog，也不为外部文件建立永久执行历史。
