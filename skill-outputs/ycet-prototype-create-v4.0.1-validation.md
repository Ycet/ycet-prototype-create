# ycet-prototype-create v4.0.1 版本说明与验证记录

- 发布包：[ycet-prototype-create-v4.0.1.skill](ycet-prototype-create-v4.0.1.skill)

- 该版本沿用 v4.0.0 的单文件、五功能和工作台契约，重点补齐属性预览、Demo 展示交互和路由触发说明。
- 相关记录：[v4.0.0 预览与路由补充验收](../docs/spec/v4.0.0/ycet-prototype-create-v4.0.0-预览与路由补充验收.md)。

## 核心变更

- 工作台属性草稿携带 `priority: "important"`；画布预览可以覆盖源 HTML 的同名 `!important` 规则，撤回时恢复完整原始样式，且不写回磁盘源文件。
- `prototype-demo` 左侧导航独立纵向滚动；右侧原型默认完整适配设备框架，右上角提供缩小、比例、放大和适应窗口按钮，展示区与页面自身均可滚动。
- Demo 手动缩放范围为 10%–300%，导航和工具栏不随原型缩放；窗口尺寸变化时重新计算适配比例。
- `SKILL.md` 将路由说明改为工作台优先、现有原型或图片其次、从零制作分阶段确认的触发流程，并加入 Mermaid 路由图。
- 同步 `VERSION`、生成器元数据、校验器和评估场景版本号为 4.0.1，保持与 v4.0.0 向后兼容。
