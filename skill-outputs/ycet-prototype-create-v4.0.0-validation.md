# ycet-prototype-create v4.0.0 版本说明与验证记录

## 版本定位

- 发布包：[ycet-prototype-create-v4.0.0.skill](ycet-prototype-create-v4.0.0.skill)
- 包含 37 个可安装文件；说明文档与发布包同级，不写入 `.skill` 压缩包。
- v4.0.0 完成五功能重组、单文件原型契约和工作台原文件修改流程，是后续 v4.x 的基础版本。
- 详细实施资料：[v4.0.0 实施与验收记录](../docs/spec/v4.0.0/ycet-prototype-create-v4.0.0-实施与验收记录.md)、[执行方案](../docs/spec/v4.0.0/ycet-prototype-create-v4.0.0-执行方案.md)。

## 核心变更

- 功能一只负责需求完善，功能二只负责 UI 方向确认，功能三统一制作原型，功能四接管现有原型或图片，功能五负责工作台。
- 功能三提供 A 静态原型页面、B 可交互原型 Demo、C 移动端演示原型 Demo；只生成用户选择的类型。
- 正式 HTML 统一写入 `prototype/outputs/`，所有页面、框架、样式、脚本和资源内联到独立文件，不依赖 `pages/`、`runtime-pages/`、iframe 或外部文件。
- 各类型独立编号；局部修改更新当前文件，高影响变更先确认是否新增迭代文件；工作台请求直接修改原文件。
- 工作台递归扫描 `prototype/` 下的原型文件，移除内容同步 `sync-pages`，取消自动创建或更新 `EditLog.md`，保留请求、摘要、事务和冲突保护。
- 图片原型保留完整位图承载，交互通过透明热区实现；不 OCR、不猜测固定区边界、不把图片自动重绘为产品 DOM。

## 未验证项与限制

- Edge、Firefox、Safari/WebKit 和 iOS/Android 真机未在本机完整运行，不能据此宣称跨浏览器或真机通过。
- `evals/evals.json` 中的行为场景已更新，但未执行独立模型的完整多轮行为评估。
- 静态守卫不能替代具体产品的逐页浏览器检查；复杂外部 HTML 仍需先在功能四中整理为可离线输入。
- 当前记录保留历史事实：该版本未安装到全局 Skill 目录、未发布到远程、未单独提交 Git。
