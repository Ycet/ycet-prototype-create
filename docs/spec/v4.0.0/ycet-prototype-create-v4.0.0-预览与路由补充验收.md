# v4.0.0 预览与路由补充验收

## 已完成

- 工作台：修复源 CSS 使用 `!important` 时，属性输入已变化而画布计算样式未变化的问题。新属性请求携带 priority，运行时兼容未携带字段的操作；撤回恢复原样式，预览不落盘。普通命名、中文任意命名及 important 样本均通过。尚未收到用户实际故障 HTML，不能认定所有潜在不同成因均已解决。
- 交互 Demo：左侧长导航独立纵向滚动；右侧默认完整适配设备框架；右上角缩小、比例、放大及适应窗口按钮仅控制原型。手动缩放 10%–300%，保持工具栏可见，溢出可滚动，页面自身长内容也可滚动。所有新生成 prototype-demo 系列适用。
- SKILL.md：将功能说明表改为触发条件和优先级，纳入用户指定 Mermaid 流程。工作台优先，其次现有原型／图片，从零流程逐阶段确认；现有 HTML 整体重设计才转 UI 方向，沿用 UI／图片承载转制作。
